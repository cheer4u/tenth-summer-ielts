# 第十個夏天 ・ 雅思單字 BL 小說

看原創 BL 小說，不知不覺背雅思單字。

- **體裁**：現代 BL（耽美）原創長篇 —— 校園同桌 → 十年重逢 → 破鏡重圓
- **內容**：全書 100 章，每章約 2,400–2,800 字（繁體中文），每章嵌入約 90 個雅思單詞，全書不重複，合計 9,051 詞
- **格式**：`word（繁體中文釋義）` 直接嵌入句流
- **兩種讀法**：
  - 學習版 Step1：在語境中背單詞——單字旁附中文，點單字看音標、發音與原句，可收進生字本
  - 複習版 Step2：看單詞回憶詞義——中文遮住，點灰色框對答案

閱讀進度與生字本保存在瀏覽器本地（localStorage）。可用手機瀏覽器「加入主畫面」當 App 使用。

版式參考「霸總教你背單字」系列，配色為 BL 粉色系（櫻花粉 × 薰衣草紫），含深色模式。

## 本地重建

網站由 `tools/build.py` 從小說 Markdown 源文件生成（`index.html` 為應用本體，`data.js` 為全書數據）。
